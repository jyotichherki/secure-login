# Secure Login & Registration Interface

## Description
A modern, responsive authentication interface built with HTML, CSS, and JavaScript. The project includes switchable Login and Register forms, real-time input validation, password visibility controls, and accessible error messages.

## Features
- Login and Registration form switching
- Email format validation
- Minimum 8-character password validation
- Confirm-password matching
- Show and hide password functionality
- Accessible validation feedback
- Responsive mobile-friendly design

## Technologies
HTML5, CSS3, JavaScript, DOM Manipulation, Event Listeners.

## How to Run
1. Clone or download the repository.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.

## Important Note
This is a frontend demonstration only. It does not create accounts, store credentials, or authenticate real users. Production authentication requires a secure backend.
